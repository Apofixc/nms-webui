# Быстрый старт NMS WebUI

Подробное пошаговое руководство по развертыванию, запуску и первичной проверке платформы NMS WebUI для пользователей, разработчиков и QA-инженеров.

---

## 📋 1. Системные требования

Для запуска платформы требуется следующее программное окружение:
* **Операционная система**: Linux (Ubuntu 20.04+, Debian 11+, Arch Linux и др.), macOS 12+, или Windows через WSL2.
* **Среда выполнения**:
  * **Python**: Версия 3.10 или 3.11+ (рекомендуется 3.11).
  * **Node.js**: Версия 18.x или 20.x LTS + `npm` 9+ (необходимы для режима разработки и сборки фронтенда).

---

## 🚀 2. Пошаговый процесс развертывания

### Шаг 1: Переход в корень проекта
```bash
cd /opt/nms-webui
```

### Шаг 2: Запуск в режиме разработки (Dev Mode)
В проекте предустановлен единый управляющий скрипт [`run_webui.sh`](file:///opt/nms-webui/run_webui.sh), который в автоматическом режиме:
1. Проверяет и создаёт виртуальное окружение Python `.venv`.
2. Устанавливает/обновляет зависимости Python из `requirements.txt`.
3. Проверяет и устанавливает npm-пакеты в директории `frontend/`.
4. Запускает **Backend (FastAPI / Uvicorn)** на порту `9000`.
5. Запускает **Frontend (Vite Dev Server)** на порту `5173`.

**Команда запуска:**
```bash
./run_webui.sh dev
```

## 🌐 3. Доступ к интерфейсу и API

После успешного запуска сервисы доступны по следующим адресам:

| Сервис | URL | Назначение |
| :--- | :--- | :--- |
| **Frontend Web UI** | `http://localhost:5173` | Главный веб-интерфейс приложения |
| **Backend REST API** | `http://localhost:9000` | Корневой адрес FastAPI бэкенда |
| **Interactive Swagger Docs** | `http://localhost:9000/docs` | Интерактивная документация OpenAPI |
| **Health Check API** | `http://localhost:9000/api/system/health` | Проверка состояния бэкенда, БД и диска |

### Учетные данные по умолчанию (Default Credentials):
* **Логин**: `admin`
* **Пароль**: `admin123`

## ⚙️ 4. Конфигурация (.env)

Параметры работы системы задаются в файле `.env` в корне проекта (`/opt/nms-webui/.env`):

```env
# Порт FastAPI backend (по умолчанию 9000)
BACKEND_PORT=9000

# Порт Vite frontend dev server (по умолчанию 5173)
FRONTEND_PORT=5173

# Отключение авторизации (только для отладки! false / true)
NO_AUTH=false

# Путь к базе данных SQLite
DB_PATH=/opt/nms-webui/backend/data/nms.db
```

## 🧪 5. Чек-лист проверки и верификации (QA Verification Checklist)

Для тестировщиков и пользователей ниже приведен пошаговый чек-лист для проверки успешности установки:

### Чек 1: Проверка статуса бэкенда и БД
Выполните команду в терминале:
```bash
curl -s http://localhost:9000/api/system/health | python3 -m json.tool
```
**Ожидаемый результат (JSON):**
* `"status": "ok"`
* `"database": {"status": "ok"}`
* Раздел `"modules"` содержит список загруженных модулей (например, `tuya` со статусом `active`).

### Чек 2: Проверка авторизации в UI
1. Откройте `http://localhost:5173` в браузере.
2. Введите `admin` / `admin123`.
3. Убедитесь, что происходит успешный вход и перенаправление на Главную страницу (Дашборд).

### Чек 3: Проверка системы документации
1. В боковом меню выберите раздел **"Документация"** (`/docs`).
2. Убедитесь, что дерево категорий слева загружается без ошибок и статьи отображаются корректно.

## 🔍 6. Устранение частых проблем (Troubleshooting)

### Ошибка: Порт занят (Address already in use)
Если порт `9000` или `5173` занят другим процессом:
1. Измените значение `BACKEND_PORT` или `FRONTEND_PORT` в файле `.env`.
2. Перезапустите `./run_webui.sh dev`.

### Сброс базы данных
Файл базы данных `nms.db` создаётся автоматически при старте бэкенда. Если требуется сбросить состояние до дефолтного:
```bash
rm -f /opt/nms-webui/backend/data/nms.db
./run_webui.sh dev
```
