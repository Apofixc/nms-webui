# 📚 Документация и встроенный справочный центр

---

## 📌 1. Назначение страницы, URL-маршруты и RBAC-права

Встроенный **Справочный центр (Documentation Center)** предоставляет операторам и разработчикам исчерпывающую справочную информацию по работе с платформой NMS WebUI напрямую из интерфейса приложения. Раздел включает руководства пользователя, описание архитектуры и инструкции по разработке кастомных модулей.

* **URL-маршрут**: `/docs`
* **Требуемые права доступа (RBAC)**: Доступна всем авторизованным пользователям (`requiresAuth: true`).

---

## 🖥 2. Подробный функциональный состав

### 2.1. Древовидное меню навигации (Sidebar Tree)
Левая панель содержит иерархическое дерево всех Wiki-статей системы:

* **Раздел 01: Обзор системы (`01-overview`)**:
  * Архитектура платформы, системные требования, стек технологий.
* **Раздел 02: Использование системы (`02-usage`)**:
  * Руководства по всем страницам и вкладкам WebUI (Дашборд, Модули, Пользователи, Роли, Профиль, Администрирование, Логи, Аудит, Авторизация, Уведомления).
* **Раздел 03: Разработка модулей (`03-module-development`)**:
  * Спецификация `manifest.json`, создание Vue SFC компонентов, интеграция REST API.

---

### 2.2. Поиск по документации (Wiki Search)
* **Поле быстрого поиска**: Позволяет искать ключевые термины по текстам всех справочных статей.
* **Результаты поиска**: Вывод с фрагментами найденного текста и возможностью перехода к нужному разделу.

---

### 2.3. Канва рендеринга Markdown (Markdown Canvas)
Центральная область отрисовки статей:

* **Поддержка GitHub Flavored Markdown (GFM)**: Списки, заголовки, таблицы, цитаты и визуальные блоки предупреждений (`[!NOTE]`, `[!IMPORTANT]`, `[!WARNING]`).
* **Подсветка синтаксиса кода**: Автоматическое выделение кода Python, JavaScript, JSON, Bash, SQL.
* **Интерактивные диаграммы Mermaid**: Отрисовка блок-схем и диаграмм последовательности процессов.

---

### 2.4. Содержание статьи (Table of Contents - TOC)
Правая панель формирует динамическое оглавление текущей открытой статьи по ее заголовкам (`H1`, `H2`, `H3`) с возможностью быстрого скроллинга к нужным секциям.

## 🔄 3. Взаимодействие с остальным приложением

```mermaid
graph TD
    UI[Frontend: DocumentationView.vue] -->|REST API| API[/api/v1/docs/*]
    API -->|Чтение файлов Markdown| FS[Files: docs/wiki/*]
    TopBar[Глобальная кнопка Справка в Топбаре] -->|Переход| UI
    WikiFiles[Файлы .md] -->|Рендеринг| UI
```

### 3.1. Backend REST API
* `GET /api/v1/docs/tree`: Загрузка структуры каталогов и файлов из папки `docs/wiki/`.
* `GET /api/v1/docs/article`: Получение исходного Markdown-текста конкретной статьи по ее пути.
* `GET /api/v1/docs/search`: Полнотекстовый поиск по корпусу документации.

### 3.2. Хранение файлов
* Документация хранится в виде обычных `.md` файлов в структуре `docs/wiki/` на сервере, что позволяет обновлять справочные материалы без повторной компиляции frontend-приложения.

### 3.3. Глобальная интеграция с интерфейсом
* В верхней шапке приложения (Topbar) размещена иконка **«Справка»** (`help`), клик по которой мгновенно открывает соответствующий раздел встроенной документации.
