# 🏗 Тестирование и Качество Кода (Testing & QA)

---

## 🧪 Стратегия тестирования

Качество и стабильность NMS WebUI обеспечиваются комплексом автоматических тестов:
- **Unit-тесты бэкенда**: Проверка отдельных функций, бизнес-логики и хелперов.
- **Интеграционные тесты API**: Проверка HTTP-эндпоинтов, авторизации, работы плагинов и БД.
- **Frontend-тесты**: Проверка корректности монтирования виджетов и composables.

---

## ⚙️ Настройка и Запуск `pytest`

Для бэкенд-тестирования используется **pytest**. Конфигурационный файл `pytest.ini` размещен в корневом каталоге проекта.

### Команды для запуска тестов:

```bash
# Запуск всех бэкенд-тестов
pytest

# Запуск тестов из конкретной директории
pytest tests/

# Запуск с подробным выводом (verbose)
pytest -v
```
