# 📖 Управление пользователями, ролями и безопасностью

---

## 📌 Раздел безопасности (`/settings/users`)

Раздел **Пользователи и Разграничение доступа** отвечает за управление аккаунтами операторов системы, назначение прав доступа (RBAC), двухфакторную аутентификацию (2FA/MFA) и контроль активных сессий.

---

## 🔐 Функциональные возможности

### 1. Управление учетными записями
- Создание новых пользователей с указанием логина, email, имени и пароля.
- Блокировка и деактивация аккаунтов.

### 2. Ролевая модель разграничения доступа (RBAC)
- Каждому пользователю назначается одна или несколько системных ролей (например, `Administrator`, `Operator`, `Viewer`).
- Роли состоят из списка атомарных разрешений (permissions), создаваемых как ядром, так и сторонними модулями.

### 3. Двухфакторная аутентификация (2FA / TOTP)
- Пользователь может включить 2FA через приложения Authenticator (Google Authenticator, YubiKey и др.).
- Система генерирует QR-код по стандарту **RFC 6238 TOTP**. При входе потребуется ввод временного 6-значного кода.

### 4. Управление активными сессиями
- Администратор видит список всех действующих JWT-сессий пользователей (IP-адрес, User-Agent, время входа).
- При необходимости любую подозрительную сессию можно отозвать в один клик.
