# 📖 Главная страница (Дашборд) и работа с виджетами

---

## 📌 1. Назначение страницы, URL-маршруты и RBAC-права

**Главная страница (Дашборд)** — это центральный оперативный консольный экран платформы NMS WebUI. На нем аккумулируются агрегированные статусы оборудования, графики загрузки сетевых интерфейсов, оперативные аварии, метрики телеметрии и элементы быстрого управления со всех активных модулей системы.

* **URL-маршрут**: `/` (или `/dashboard`)
* **Требуемые права доступа (RBAC)**: Доступна всем авторизованным пользователям (`requiresAuth: true`). Отображение конкретных виджетов дополнительно фильтруется на основе прав доступа текущего пользователя (например, виджеты управления пользователями требуют право `users.view`).

## 🖥 2. Подробный функциональный состав

### 2.1. Верхняя панель управления (Action Bar)
Верхняя панель предоставляет средства управления макетом и виджетами:

1. **Кнопка «Добавить виджет» (`+ Add Widget`)**:
   * Открывает всплывающее модальное окно **Каталога виджетов**.
   * Доступна как в обычном режиме просмотра, так и в режиме кастомизации.

2. **Переключатель «Режим кастомизации» (`Customize Dashboard / Done`)**:
   * Переключает интерфейс между режимом оперативного мониторинга и режимом редактирования макета.
   * При активации раскрываются дополнительные инструменты: Snap-to-Grid, выбор режима коллизий, управление пресетами, экспорт/импорт макетов и сброс позиций.

3. **Привязка к сетке (`Snap to Grid`)** *(в режиме кастомизации)*:
   * Чекбокс, включающий автоматическое выравнивание перемещаемых карточек по дискретным шагам 12-колоночной сетки.

4. **Выбор режима коллизий (`Collision Mode`)** *(в режиме кастомизации)*:
   * **Выталкивание (`push`)**: При перемещении виджета на занятое место соседние виджеты автоматически смещаются вниз.
   * **Блокировка (`block`)**: Перемещение блокируется, если целевые ячейки сетки перекрываются с другим виджетом.
   * **Свободный нахлест (`off`)**: Виджеты могут перекрывать друг друга без смещения.

5. **Управление пресетами макетов (`Presets`)** *(в режиме кастомизации)*:
   * Выпадающий список сохраненных пользователем макетов (например, *«Оперативный мониторинг»*, *«Сетевые трассировки»*, *«Системный аудит»*).
   * Кнопка **«Сохранить пресет»** (`bookmark_add`): сохраняет текущее состояние сетки под новым именем.

6. **Экспорт и Импорт макета (`Export JSON` / `Import JSON`)** *(в режиме кастомизации)*:
   * **Экспорт**: Скачивает JSON-файл с полной конфигурацией всех рабочих столов и виджетов.
   * **Импорт**: Загружает макет из JSON-файла, позволяя мгновенно переносить рабочие пространства между операторами.

7. **Кнопка «Сбросить макет» (`Reset Layout`)**:
   * Возвращает расположение и набор виджетов активного рабочего стола к заводской конфигурации по умолчанию.

### 2.2. Навигация по рабочим столам (Multi-Desktop Workspaces)
Система поддерживает многоэкранную организацию рабочего пространства:

* **Вкладки рабочих столов (Desktop Tabs)**: Позволяют создавать несколько независимых экранов мониторинга (например, *Рабочий стол 1*, *Серверная*, *Сетевые каналы*).
* **Горизонтальная прокрутка вкладок**: При большом количестве столов доступна плавное колесико мыши для скроллинга панели вкладок.
* **Контекстные действия со столом**:
  * **Переименование (`Rename`)**: Изменение наименования рабочего стола.
  * **Дублирование (`Duplicate`)**: Создание точной копии текущего стола со всеми его виджетами и сеткой.
  * **Удаление (`Delete`)**: Удаление рабочего стола (доступно, если в системе создано более одного стола).

---

### 2.3. Интерактивная 12-колоночная сетка (Grid System)
* **Адаптивность**: Сетка автоматически подстраивается под ширину экрана оператора (от мобильных планшетов до UltraWide-мониторов).
* **Размеры карточек виджетов**:
  * `Small` (1x1 или 2x1): Компактные цифровые индикаторы, статусные счетчики аварий.
  * `Medium` (2x2 или 3x2): Круговые диаграммы, сводные таблицы состояния.
  * `Large` (4x2, 4x3 и более): Полноразмерные графики временных рядов, интерактивные сетевые карты и текстовые консоли логов.
* **Drag & Drop**: В режиме кастомизации захват за заголовок карточки позволяет свободно перемещать ее по экрану.
* **Динамический Resize**: Захват за нижний правый угол карточки позволяет изменять ее ширину и высоту.
* **Удаление виджета**: Нажатие на кнопку `×` в шапке виджета сразу убирает его с текущего рабочего стола.

---

### 2.4. Каталог виджетов (Widget Catalog)
* **Категории**: Группировка виджетов по принадлежности — `Ядро`, `Сбор данных`, `Мониторинг`, `Устройства`.
* **Поиск**: Поле быстрого текстового фильтра по названию и описанию виджета.
* **Добавление**: Кнопка `+ Добавить` помещает виджет на первую свободную позицию сетки активного рабочего стола.

## 🔄 3. Взаимодействие с остальным приложением

```mermaid
graph TD
    UI[Frontend: Dashboard.vue] -->|REST API GET/POST| API_Layout[/api/v1/dashboard/layout/]
    UI -->|REST API GET| API_Widgets[/api/v1/widgets/catalog/]
    UI -->|WebSocket Sub| WS[/ws/telemetry]
    API_Layout -->|Чтение/Запись| DB[(SQLite: nms.db - dashboard_layouts)]
    UI -->|Регистрация виджетов| Registry[modules/registry.ts]
    WS -->|Стриминг метрик| Core[Backend System Core]
```

### 3.1. Backend REST API
* `GET /api/v1/dashboard/layout`: Загрузка сохраненного персонального макета текущего пользователя из БД.
* `POST /api/v1/dashboard/layout`: Сохранение изменений сетки, списка столов, выбранного пресета и расположения виджетов.
* `GET /api/v1/widgets/catalog`: Получение реестра доступных системных и модульных виджетов.

### 3.2. База данных `nms.db`
* Таблица `dashboard_layouts`: Хранит JSON-структуру персональных настроек каждого оператора (`user_id`, `desktops`, `active_preset`, `updated_at`).

### 3.3. WebSockets и Real-time обновление
* Виджеты телеметрии подключаются к WebSocket-каналу `/ws/telemetry`.
* При поступлении новых метрик или аварий виджеты обновляют графики и индикаторы без перезагрузки страницы.
* Для обычных виджетов действует резервный polling-таймер (автообновление раз в 5 секунд).

### 3.4. Модульная архитектура
* Модули приложения расширяют Дашборд, регистрируя свои кастомные Vue-компоненты через `modules/registry.ts`.
* Отключение модуля в разделе «Управление модулями» автоматически скрывает его виджеты с Дашборда.

### 3.5. Безопасность и аудит
* Сохранение, экспорт и сброс макетов фиксируются в `SecurityAuditLog`.
* Права доступа текущей сессии фильтруют отображение виджетов: если у пользователя отозвано право `system.admin`, административные виджеты автоматически удаляются из показа.
