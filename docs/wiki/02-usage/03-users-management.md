# 📖 Управление пользователями и операторами

---

## 📌 Назначение раздела (`/settings/users`)

Раздел **Управление пользователями** предоставляет администраторам платформы инструменты для централизованного контроля учетных записей операторов, сброса паролей, блокировки аккаунтов и массового экспорта данных.

---

## 👤 Функциональные возможности и интерфейс

### 1. Таблица и реестр операторов
- **Строки пользователей**: Отображают логин, ФИО, Email, роль в системе, статус двухфакторной аутентификации (2FA) и дату последнего входа.
- **Индикаторы статуса**:
  - 🟢 `Active`: Активный оператор.
  - 🔴 `Locked`: Учетная запись заблокирована.
  - 🛡️ `MFA Enabled`: Для пользователя активирован 2FA (TOTP).

---

### 2. Фильтрация и поиск
- **Текстовый поиск**: Быстрый фильтр по логину, имени и Email оператора.
- **Фильтр по статусу**: Выпадающий список (`Все`, `Только активные`, `Заблокированные`, `С 2FA/MFA`).
- **Счетчик операторов**: Отображает текущее количество найденных аккаунтов.

---

### 3. Форма добавления и редактирования пользователя
- **Кнопка "Добавить пользователя"**: Открывает модальное окно создания аккаунта.
- **Обязательные поля**:
  - **Логин (Username)**: Уникальный системный идентификатор.
  - **Пароль и подтверждение**: Обязательная проверка сложности пароля.
  - **ФИО и Email**: Данные для уведомлений и профиля.
  - **Назначение роли**: Выбор одной или нескольких ролей (`Administrator`, `Operator`, `Viewer`).
- **Флаг "Требовать смену пароля"**: При активации пользователь будет обязан сменить пароль при следующем входе.

---

### 4. Групповые операции (Bulk Actions)
- **Множественный выбор**: Галочки напротив пользователей активируют нижнюю панель групповых действий.
- **Доступные действия**:
  - **Групповая блокировка**: Мгновенное деактивирование выбранных аккаунтов.
  - **Групповая разблокировка**: Восстановление доступа.
  - **Принудительный сброс паролей**: Отправка флага обязательной смены пароля.

---

### 5. Экспорт списка операторов
- **Кнопка "Экспорт CSV"**: Скачивание таблицы пользователей в формате `.csv` для отчетов.
- **Кнопка "Экспорт JSON"**: Выгрузка реестра в формате `.json` для внешних систем аудита.
