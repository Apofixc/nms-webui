# ⚙️ Аутентификация, RBAC и Безопасность

---

## 🔐 Аутентификация и Сессии

NMS WebUI поддерживает авторизацию пользователей с использованием безопасности JWT (JSON Web Tokens) или сессионных токенов с шифрованием.

### Механизм работы:
1. Пользователь передает логин и пароль в эндпоинт `/api/v1/auth/login`.
2. После валидации генерируется access-токен с ограниченным сроком действия.
3. Все последующие запросы отправляются с заголовком `Authorization: Bearer <token>`.

---

## 🛡 Ролевая модель доступа (RBAC)

Система ограничений прав построена по модели **RBAC (Role-Based Access Control)**.

### Предопределенные роли:
- **`Admin`**: Полный доступ ко всем эндпоинтам, плагинам, настройкам системы и управлению пользователями.
- **`Operator`**: Доступ к мониторингу, управлению устройствами, просмотру видеопотоков и подтверждению тревог.
- **`Viewer`**: Доступ только для чтения (просмотр дашбордов и текущих статусов).

---

## 📋 Журнал Аудита (Audit Log)

Каждое критическое действие пользователя (вход в систему, изменение конфигураций, управление устройствами, удаление объектов) автоматически записывается в журнал аудита.
