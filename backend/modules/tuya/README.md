# 🔌 Модуль Tuya IoT Driver

Модуль драйвера Tuya обеспечивает прямое интеграционное взаимодействие с экосистемой умных устройств Tuya по локальному протоколу и облачному API.

## Поддерживаемые функции:
- Сканирование и привязка умных розеток, выключателей и термостатов.
- Мониторинг статуса (Online/Offline) и замер энергопотребления.
- Встроенные виджеты быстрого переключения для Дашборда.
