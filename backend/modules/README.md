# Модули NMS-WebUI (🧩 Plugins)

Эта директория содержит бизнес-логику приложения, организованную в виде независимых загружаемых модулей.

## Быстрый старт

Каждый модуль должен находиться в собственной папке и содержать файл `manifest.yaml`.

### Пример структуры
```text
modules/
  ├── base.py              # Базовые классы BaseModule/BaseSubmodule
  └── my-module/           # Ваш новый модуль
      ├── manifest.yaml    # Манифест (название, роуты, зависимости)
      ├── locales/         # Файлы локализации модуля (ru.json, en.json)
      │   ├── ru.json
      │   └── en.json
      ├── __init__.py      # Точка входа для загрузчика
      ├── module.py        # Логика жизненного цикла
      └── api.py           # API эндпоинты
```

## Основные правила
1. **Изоляция**: Модуль не должен напрямую импортировать логику из других модулей. Используйте зависимости в манифесте (`deps`).
2. **Манифест**: Файл `manifest.yaml` является единственным источником истины для построения меню и роутинга как на бэкенде, так и на фронтенде.
3. **Жизненный цикл**: Обязательно реализуйте методы `init`, `start` и `stop` в классе вашего модуля.
4. **Локализация**: Единственный допустимый стандарт локализации модуля — хранение JSON-файлов в папке `locales/` (`locales/ru.json`, `locales/en.json`). Использование блоков переводов внутри `manifest.yaml` запрещено.
