# 📖 Просмотр логов, Журнал аудита и Здоровье системы

---

## 📌 Мониторинг и администрирование системы

Разделы управления системным состоянием платформы служат для контроля за работой Uvicorn бэкенда, SQLite базы данных и аудита действий операторов.

---

## 🔍 Функциональные возможности

### 1. Просмотр системных логов (`/system/logs`)
- Веб-консоль просмотра журналов выполнения бэкенда в режиме реального времени.
- **Фильтрация**: По уровням логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`) и ключевым словам.
- **Источники**: Переключение между логами ядра NMS и отдельными провайдерами логов подключенных модулей.

### 2. Журнал аудита безопасности (`/system/audit`)
- Неизменяемый реестр всех критических событий платформы:
  - Авторизация и входы пользователей.
  - Изменение настроек модулей.
  - Управление устройствами и сбросы параметров.
- Для каждой записи фиксируются: штамп времени, имя пользователя, выполненное действие (`ACTION`), целевой объект (`TARGET`), подробности в формате JSON и IP-адрес клиента.

### 3. Детализированный статус здоровья (Healthcheck API)
- Системный эндпоинт `/api/system/health` проверяет:
  - Доступность базы данных SQLite.
  - Использование дискового пространства в процентах и свободных ГБ.
  - Статусы всех загруженных модулей.
