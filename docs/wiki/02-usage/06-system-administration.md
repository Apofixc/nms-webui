# 📖 Системное администрирование

---

## 📌 Назначение раздела (`/settings/system`)

Раздел **Системное администрирование** предназначен для операторов уровня `Administrator` (`system.admin`). Он содержит инструменты создания резервных копий БД, контроля за активными сессиями пользователей, ротации аудита и диагностики здоровья сервера.

---

## 🛠️ Функциональные возможности и интерфейс

### 1. Резервное копирование и Восстановление (Backup & Restore)
- **Скачивание дампа базы данных**:
  - Кнопка **"Скачать бэкап"**: Формирует мгновенную резервную копию файла базы данных `nms.db` со всеми настройками, ролями и состояниями устройств.
- **Восстановление из бэкапа**:
  - Кнопка **"Восстановить бэкап"**: Позволяет загрузить `.db` файл резервной копии. Система выполнит проверку целостности таблиц и безопасно обновит базу данных.
- **Ротация аудита (Rotate Audit)**:
  - Кнопка **"Ротировать журнал аудита"**: Позволяет архивировать устаревшие записи аудита для освобождения дискового пространства.

---

### 2. Активные JWT-сессии пользователей (Active Sessions & Security)
- **Мониторинг подключений**: Отображает список всех действующих сессий операторов в реальном времени.
- **Детализация каждой сессии**:
  - Логин пользователя и IP-адрес клиента.
  - User-Agent (браузер, версия ОС).
  - Время создания сессии и дата последнего активного запроса.
- **Экстренное завершение сессий**:
  - **"Завершить сессии других"**: Отозвать JWT-токены всех остальных пользователей, кроме текущего администратора.
  - **"Завершить ВСЕ сессии и выйти"**: Экстренный полный разрыв всех подключений.

---

### 3. Мониторинг ресурсов и Здоровье системы (System Health)
- **Виджет статуса бэкенда**: Показывает доступность Uvicorn/FastAPI бэкенда (`Status: OK`).
- **Состояние SQLite БД**: Индикатор доступности файла базы данных и времени отклика на тестовый SQL-запрос.
- **Использование диска**:
  - Процент заполнения системного раздела (в GB и %).
  - Предупреждающий баннер при заполнении диска свыше 95%.
- **Статус загрузки модулей**: Отображает количество активных и отключенных модулей ядра.
