# Быстрый старт (Quick Start)

## Системные требования и зависимости [icon:fact_check]

Для разворачивания и комфортной работы NMS WebUI убедитесь, что ваш сервер или рабочая станция соответствуют минимальным требованиям.

### Операционная система
- **Linux**: Ubuntu 20.04+, Debian 11+, RHEL / Rocky Linux 8+, Alpine Linux.
- **macOS**: macOS 12 Monterey или новее.
- **Windows**: Windows 10/11 через среду **WSL2** (Ubuntu / Debian).

### Программное окружение
- **Python**: версия `3.10` или новее (требуются пакеты `python3-venv`, `python3-dev`).
- **Node.js**: версия `18.x` или новее (с поддержкой `npm` или `pnpm`).
- **Системные утилиты**: `bash`, `git`, `lsof`, `procps`, `build-essential`.

### Рекомендуемые аппаратные ресурсы
- **CPU**: 2 ядра x86_64 или ARM64.
- **RAM**: от 2 ГБ оперативной памяти.
- **Диск**: от 1 ГБ свободного пространства для кода, БД и логов.

## Установка и локальный запуск одной командой [icon:download]

Система NMS WebUI поставляется с универсальным скриптом `run_webui.sh`, который автоматизирует процесс установки системных библиотек, создания виртуального окружения Python и сборки пакетов Node.js.

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-org/nms-webui.git
cd nms-webui
```

### 2. Автоматическая установка одной командой
```bash
./run_webui.sh install
```
*Скрипт самостоятельно установит необходимые системные библиотеки через apt (на Debian/Ubuntu), создаст окружение `.venv`, установит зависимости Python и зависимости фронтенда npm.*

### 3. Локальный запуск в режиме разработки
```bash
./run_webui.sh dev
```
После выполнения команды автоматически запустятся:
- **Backend API**: `http://localhost:9000` (FastAPI / Swagger документация доступна на `/docs`)
- **Frontend UI**: `http://localhost:5173` (Vite dev server с поддержкой Hot Module Replacement)

### 4. Полный запуск в тестовом окружении
Для отладки мониторинга без физического оборудования используйте тестовый запуск с автоматической генерацией сигналов:
```bash
./run_webui.sh test
```

### 5. Остановка всех сервисов
```bash
./run_webui.sh stop
```

## Конфигурация первого запуска [icon:tune]

### Переменные окружения (`.env`)
В корневом каталоге проекта при необходимости создайте файл `.env` на основе примера `.env.example`:

```ini
# Путь к файлу со списком медиа-инстансов
NMS_INSTANCES_FILE=instances.yaml

# Уровень логирования бэкенда (DEBUG, INFO, WARNING, ERROR)
NMS_LOG_LEVEL=INFO

# Таймаут запросов к внешним инстансам в секундах
NMS_REQUEST_TIMEOUT=10.0

# Интервал автоматической проверки состояния инстансов (в секундах)
NMS_CHECK_INTERVAL_SEC=30
```

### Настройка подключаемых инстансов (`instances.yaml`)
Отредактируйте файл `instances.yaml` для указания серверов вещания:

```yaml
instances:
  - label: "Astra Main Node"
    host: "127.0.0.1"
    port: 8000
    api_key: "your_secret_api_key"
```

### Полезные флаги запуска
- **Отключение авторизации (без формы входа для девелопмента)**:
  ```bash
  ./run_webui.sh dev --no-auth
  ```
- **Сброс пароля суперадминистратора**:
  ```bash
  ./run_webui.sh reset-root
  ```
