# Архитектура NMS WebUI

Обзор архитектурных слоёв, компонентов и взаимодействия сервисов NMS WebUI.

## Высокоуровневая схема

```
┌─────────────────────────────────────────────────────────┐
│                    Frontend (Vue 3)                     │
│        Vite + TypeScript + Tailwind CSS + Pinia         │
└───────────────────────────┬─────────────────────────────┘
                            │ REST / WebSocket API
┌───────────────────────────▼─────────────────────────────┐
│                    Backend (FastAPI)                    │
│   Auth (JWT) ── System API ── Event Bus ── Modules API  │
└─────┬─────────────────────┬──────────────────────┬──────┘
      │                     │                      │
┌─────▼──────┐       ┌──────▼──────┐        ┌──────▼──────┐
│  SQLite    │       │ Модули (e.g.│        │ MediaMTX    │
│  (nms.db)  │       │    Tuya)    │        │ (Video RTSP)│
└────────────┘       └─────────────┘        └─────────────┘
```

## Основные компоненты

1. **Backend (Python / FastAPI)**:
   - `backend/main.py` — Точка входа приложения.
   - `backend/core/` — Базовые сервисы: авторизация (`auth.py`), база данных (`database.py`), логирование (`audit.py`), системное API (`system_api.py`).
   - `backend/modules/` — Динамически подгружаемые модули расширения.

2. **Frontend (Vue 3 + Vite)**:
   - `src/views/` — Экраны (Дашборд, Настройки, Логи, Модули, Документация).
   - `src/components/layout/` — Каркас интерфейса (Sidebar, Header, SettingsRail).
   - `src/core/` — Роутер, клиенты API (`api.ts`), i18n локализация.

3. **База данных (SQLite / nms.db)**:
   - Таблицы пользователей, сессий, аудита, настроек модулей и состояний устройств.

4. **Система модулей**:
   - Каждый модуль изолирован в своей директории и может предоставлять backend-эндпоинты, frontend-виджеты, локализацию и настройки.
