# Быстрый старт NMS WebUI

Быстрое руководство по разворачиванию и запуску платформы NMS WebUI в режиме разработки и продакшн.

## Требования к окружению

- **Python**: 3.10+
- **Node.js**: 18+ и npm
- **ОС**: Linux / macOS / WSL2 (Ubuntu 20.04+)

## Установка и запуск

1. **Клонирование и переход в проект**:
   ```bash
   cd /opt/nms-webui
   ```

2. **Запуск в режиме разработки**:
   В корне проекта расположен скрипт `run_webui.sh`, который автоматически создаёт virtualenv, устанавливает зависимости Python и npm, после чего запускает Backend (Uvicorn) и Frontend (Vite):
   ```bash
   ./run_webui.sh dev
   ```

3. **Доступ к веб-интерфейсу**:
   - Веб-интерфейс: `http://localhost:5173` (или указанный Vite порт)
   - REST API Swagger Docs: `http://localhost:8000/docs`

## Переменные окружения

Создайте файл `.env` в корне проекта при необходимости переопределить порты:
```env
BACKEND_PORT=8000
FRONTEND_PORT=5173
NO_AUTH=false
```
