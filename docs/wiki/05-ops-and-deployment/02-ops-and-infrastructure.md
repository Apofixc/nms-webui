## 💾 База данных SQLite в режиме WAL

Основная база данных NMS WebUI — файл **`nms.db`**, работающий под управлением движка SQLite3 в режиме **WAL (Write-Ahead Logging)**.

### Преимущества режима WAL:
- Операции чтения не блокируют операции записи.
- Существенно возрастает производительность при высокой частоте сбора метрик.

### Резервное копирование БД:
Для создания горячей резервной копии базы данных без остановки сервиса используйте утилиту `sqlite3`:

```bash
sqlite3 nms.db ".backup 'nms_backup_$(date +%Y%m%d_%H%M%S).db'"
```

## 📝 Логирование и диагностика

Логи приложения записываются в корневом каталоге проекта:
- **`backend.log`**: Основной журнал бэкенда (запросы, ошибки API, старт плагинов).
- **`astra.log`**: Лог специфичных служб мониторинга и драйверов.
- **`mcp-server.log`**: Лог протокола управления и сервисных процессов.
