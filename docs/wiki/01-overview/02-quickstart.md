# 🚀 Быстрый старт и скрипт управления

---

## 📌 Управление сервисом через `run_webui.sh`

Для запуск, остановки и проверки состояния платформы NMS WebUI используется единый исполнения скрипт **`run_webui.sh`**, находящийся в корневой директории приложения.

---

## 🛠 Команды управления

### 1. Запуск в режиме разработки (`dev`)
```bash
./run_webui.sh dev
```
*Запускает FastAPI бэкенд на порту 8000 и Vite dev-сервер фронтенда на порту 5173 с автоперезагрузкой при изменении исходников.*

### 2. Запуск в продакшн режиме (`start`)
```bash
./run_webui.sh start
```
*Запускает бэкенд на Uvicorn и раздает собранные статичные файлы фронтенда.*

### 3. Проверка статуса сервиса (`status`)
```bash
./run_webui.sh status
```
*Проверяет активность процессов бэкенда и фронтенда, открытые порты и состояние диска.*

### 4. Остановка приложения (`stop`)
```bash
./run_webui.sh stop
```
*Корректно завершает процессы NMS WebUI без повреждения базы данных SQLite.*

---

## 🔑 Первичный вход и учетные данные

При первом старте система автоматически создает учетную запись главного администратора:
- **Логин**: `root`
- **Пароль по умолчанию**: `root` (систем рекомендует изменить его сразу после входа в профиле).
