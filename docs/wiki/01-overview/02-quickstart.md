# 🚀 Быстрый старт, команды скрипта и конфигурация

---

## 💻 Системные требования

Перед развертыванием NMS WebUI убедитесь, что рабочее окружение соответствует следующим требованиям:

- **Операционная система**: Linux (Ubuntu 20.04+, Debian 11+, RHEL/Rocky Linux 8+) или POSIX-совместимая среда.
- **Python**: Версия `3.10` или выше (требуется `python3-venv` и `python3-dev`).
- **Node.js**: Версия `18.x` или `20.x` LTS (с пакетным менеджером `npm`).
- **Системные утилиты**: `build-essential`, `lsof`, `procps`, `sqlite3`, `bash`, `curl`.

## ⚡️ Управление платформой через `./run_webui.sh`

В корневом каталоге проекта расположен универсальный управляющий скрипт `run_webui.sh`. Он автоматически обрабатывает создание виртуального окружения Python, установку Node-пакетов, очистку занятых портов и параллельный запуск бэкенда и фронтенда.

### Использование:
```bash
./run_webui.sh <команда> [опции]
```

### Основные команды скрипта:

| Команда | Назначение | Что происходит при запуске |
| :--- | :--- | :--- |
| **`install`** | Полная первичная установка | Установка системных библиотек via `apt-get`, создание `.venv`, установка Python-пакетов (`fastapi`, `uvicorn`, `pydantic`, `httpx`, `celery` и др.) и выполнение `npm install` в `frontend/`. |
| **`dev`** | Обычный режим разработки | Очистка занятых портов (9000, 5173), автоматическое создание `.venv` (при отсутствии), запуск FastAPI бэкенда и Vite dev-сервера. |
| **`stop`** | Полная остановка системы | Завершение процессов по портам (`9000`, `5173`) и остаточных процессов `uvicorn` и `vite`. |
| **`backend`** | Только бэкенд | Запуск только FastAPI сервера (порт 9000 по умолчанию). |
| **`frontend`** | Только фронтенд | Запуск только Vite dev-сервера (порт 5173 по умолчанию). |
| **`worker`** | Celery Worker | Запуск асинхронного воркера фоновых задач Celery (`celery -A main.celery_worker worker`). |
| **`reset-root`** | Сброс доступа суперпользователя | Восстановление учетной записи `root` и сброс её пароля к стандартному значению `admin` via `backend.scripts.reset_root`. |

### Флаги и переменные окружения:

```bash
# Отключение формы авторизации (авто-вход под учётной записью Superuser)
./run_webui.sh dev --no-auth
# или через переменную окружения
NMS_DISABLE_AUTH=1 ./run_webui.sh dev

# Переопределение портов бэкенда и фронтенда
NMS_PORT=9500 NMS_FRONTEND_PORT=3000 ./run_webui.sh dev
```

## ⚙️ Переменные окружения (`.env`)

Настройки системы считываются из переменных окружения или файла `.env` в корне проекта (создаётся на основе `.env.example`). Все параметры приложения имеют префикс `NMS_`:

```env
# Сетевые порты (для скрипта run_webui.sh)
NMS_PORT=9000
NMS_FRONTEND_PORT=5173

# Логирование и таймауты бэкенда
NMS_LOG_LEVEL=INFO
NMS_REQUEST_TIMEOUT=10.0
NMS_CHECK_INTERVAL_SEC=30

# Celery / Брокер сообщений
NMS_CELERY_BROKER_URL=pyamqp://guest@localhost//

# Отключение авторизации (только для тестовых и отладочных стендов!)
NMS_DISABLE_AUTH=0
```

## 🏁 Первичный вход и проверка работоспособности

1. **Запустите систему в dev-режиме**:
   ```bash
   ./run_webui.sh dev
   ```
2. **Откройте браузер** по адресу: `http://localhost:5173` (или IP вашего сервера).
3. **Авторизация по умолчанию**:
   - **Логин**: `root`
   - **Пароль**: `admin`
4. **Первичные шаги администратора**:
   - При первом входе рекомендуется сменить стандартный пароль `admin` на стойкий в меню профиля `/user/profile` или в настройках системной безопасности.
5. **Проверка статуса здоровья системы**:
   - Перейдите по адресу `http://localhost:9000/health` (или `http://localhost:9000/api/health`) для получения JSON-отчета о статусе базы данных, свободном месте на диске и модулях системы.
