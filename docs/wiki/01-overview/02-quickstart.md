# 🚀 Быстрый старт и конфигурация

---

## 💻 Системные требования

Перед запуском убедитесь, что в рабочей системе установлены:
- **ОС**: Linux / POSIX-совместимая операционная система (Ubuntu 20.04+, Debian 11+).
- **Python**: Версия `3.10` или выше.
- **Node.js**: Версия `18+` (и пакетный менеджер `npm`).
- **Bash / Shell**: Стандартная оболочка для выполнения скриптов управления.

---

## ⚡️ Запуск одной командой

Для развертывания всего стека приложения (Backend + Frontend + MediaMTX + SQLite) используется скрипт `run_webui.sh`, расположенный в корневом каталоге проекта.

Выполните команду в терминале:

```bash
./run_webui.sh
```

### Что происходит при выполнении `run_webui.sh`:
1. **Проверка окружения**: Проверяется наличие Python 3, Node.js и необходимых утилит.
2. **Создание venv**: Автоматически инициализируется виртуальное окружение Python в каталоге `.venv`.
3. **Установка зависимостей**:
   - Backend: установка pip-пакетов из требований.
   - Frontend: выполнение `npm install` в каталоге `frontend/`.
4. **Конфигурация**: Проверяется наличие файла `.env`. Если он отсутствует, создается копия из `.env.example`.
5. **Запуск сервисов**:
   - Старт бэкенд-сервера FastAPI.
   - Старт dev-сервера фронтенда Vite.
   - Инициализация и подключение MediaMTX.

---

## ⚙️ Конфигурационные файлы

### 1. Файл переменных окружения `.env`
Создается автоматически из файла-шаблона `.env.example`. Основные параметры:

```env
# Сервер и Порты
HOST=0.0.0.0
PORT=8000
SECRET_KEY=your-super-secret-key-change-it

# База данных
DATABASE_URL=sqlite:///./nms.db

# Логирование
LOG_LEVEL=INFO
```

### 2. Конфигурация экземпляров `instances.yaml`
Файл `instances.yaml` содержит описание подключаемых серверов, узлов и источников данных:

```yaml
instances:
  - id: local-node-1
    name: "Основной узел NMS"
    host: "127.0.0.1"
    enabled: true
```
