# 📖 Разграничение доступа и Политики безопасности

---

## 📌 Назначение раздела (`/settings`)

Раздел **Доступ и Разграничение прав** отвечает за настройки ролевой модели доступа (RBAC) и общесистемные политики аутентификации платформы NMS WebUI.

---

## 🛡️ Функциональные возможности и интерфейс

### 1. Глобальные политики безопасности (Security Policies)
- **Переключатель "Глобальная аутентификация"**:
  - При выключении система переходит в открытый режим работы (рекомендуется только для изолированных тестовых сред).
  - При включении все страницы и API закрываются требованием валидного JWT-токена.
- **Обязательная смена пароля при первом входе**: Принуждает новых пользователей задавать индивидуальный безопасный пароль.
- **Принудительный 2FA/MFA для администраторов**: Запрещает вход учетным записям с правами `system.admin` без настроенного TOTP-аутентификатора.
- **Таймаут JWT-сессии**: Задание времени жизни токена авторизации (в минутах/часах).
- **Защита от подбора паролей (Brute-Force Protection)**: Задание максимального количества неудачных попыток входа до временной блокировки IP-адреса.

---

### 2. Матрица ролей и разрешений (RBAC Roles Management)
- **Список системных и кастомных ролей**:
  - **`Administrator`**: Полные права управления всей платформой, бэкапами и пользователями.
  - **`Operator`**: Права на управление оборудованием, устройствами и просмотр виджетов.
  - **`Viewer`**: Права только на чтение графиков и статусов без возможности изменения настроек.
- **Создание и удаление ролей**: Кнопка **"Создать роль"** позволяет объявлять новые роли операторов под спецификацию вашей организации.

---

### 3. Настройка разрешений (Permissions Matrix)
- **Двухмерная сетка чекбоксов**: Администратор может точно выбирать, какие права привязаны к роли.
- **Категории разрешений**:
  - **Ядро (Core)**: `system.admin`, `users.view`, `users.manage`, `modules.view`, `roles.view`.
  - **Модули (Module Scoped Permissions)**: Динамические права, экспортируемые плагинами (например, `tuya.control`, `modbus.read`).
- **Кнопка "Применить изменения"**: Сохраняет обновленную матрицу прав в БД SQLite с мгновенным вступлением в силу для всех авторизованных пользователей.
