# Конфигурация и обслуживание NMS WebUI

Инструкции по настройке параметров окружения, бэкапам и логированию.

## Переменные окружения (`.env`)

```env
# Порты сервисов
BACKEND_PORT=8000
FRONTEND_PORT=5173

# Флаги авторизации
NO_AUTH=false

# Пути
DB_PATH=/opt/nms-webui/nms.db
```

## Резервное копирование и восстановление

- **Автоматический бэкап**: Базу данных `nms.db` можно бэкапить копированием файла при остановленном сервисе или вызовом `GET /api/system/backup`.
- **Восстановление**: Восстановление производится вызовом `POST /api/system/restore` с передачей файла `.db`.

## Управление сессиями

В разделе системных настроек администратор может просматривать активные сессии пользователей и выполнять их сброс при необходимости.
