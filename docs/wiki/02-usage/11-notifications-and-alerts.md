# 📖 Центр уведомлений и Внешние интеграции

---

## 📌 Назначение Центра уведомлений (`NotificationCenter`)

**Центр уведомлений** расположен в верхней постоянной шапке (Header) веб-интерфейса NMS WebUI. Он отвечает за немедленное оповещение операторов о критических сетевых авариях, событиях оборудования, изменениях статусов модулей и передачу алертов во внешние мессенджеры и корпоративные системы.

---

## 🔔 Функциональные возможности и интерфейс

### 1. Колокольчик в шапке (Header Notification Badge)
- **Иконка с индикатором**: Отображается на всех страницах системы справа в верхней панели.
- **Счетчик непрочитанных алертов**: При появлении новых событий высвечивается красная бляшка с числом непрочитанных уведомлений (например, `3` или `99+`).
- **Пульсация алертов**: При получении критической сетевой аварии иконка активирует визульное привлечение внимания.

---

### 2. Выпадающая панель событий (Popover Panel)
- **Категории и уровни критичности**:
  - 🔴 **Critical / Error**: Отказ оборудования, потеря связи, критический выгружаемый аварийный статус.
  - 🟡 **Warning**: Выход параметров за порог предупреждения, предупреждения о переполнении диска.
  - 🔵 **Info / Success**: Информационные системные сообщения (успешное обновление модуля, завершение ротации бэкапа).
- **Фильтрация и Поиск**: Текстовое поле поиска по истории уведомлений и быстрое переключение фильтра (`Все`, `Только критические`, `Непрочитанные`).
- **Управление статусом**:
  - Кнопка **"Прочитать все"**: Мгновенно снимает счетчик необработанных уведомлений.
  - Кнопка **"Очистить историю"**: Удаляет старые локальные оповещения.

---

### 3. Звуковые оповещения и Web Push
- **Звуковые уведомления (Sound Notifications)**: Переключатель динамика (🔊) включает звуковые сигналы при поступлении критических тревог.
- **Системные Web Push-уведомления**: Переключатель колокольчика запрашивает разрешение браузера на отправку всплывающих Push-уведомлений ОС, позволяя оператору получать тревоги даже при свернутом браузере.

---

### 4. Внешние интеграции и каналы доставки (Notification Integrations)
Нажатие иконки **"Интеграции" (`hub`)** в шапке выпадающей панели открывает окно настройки внешних каналов оповещений:
- **Telegram Bot**: Настройка Telegram Bot API (Token и Chat ID) для дублирования тревог в оперативный дежурный чат.
- **Webhooks**: Направление JSON-пайлоадов алертов на сторонние HTTP API / SIEM-системы.
- **Email / SMTP**: Настройки отправки почтовых сообщений на адреса дежурных инженеров.
- **Slack / Discord**: Интеграция с корпоративными мессенджерами через Webhook URL.
