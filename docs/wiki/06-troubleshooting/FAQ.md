# Частые вопросы (FAQ) и решение проблем

Решения распространенных проблем при разработке, развертывании и эксплуатации системы NMS WebUI.

---

## ❓ Вопросы и пошаговые решения

### 1. Как сбросить пароль администратора при утрате доступа?

Если вы потеряли пароль от учётной записи администратора:
1. Временно запустите backend в режиме отладки без авторизации:
   ```bash
   NO_AUTH=true ./run_webui.sh dev
   ```
2. Откройте интерфейс `http://localhost:5173`, перейдите в **Управление пользователями** и смените пароль у пользователя `admin`.
3. Перезапустите веб-интерфейс в обычном режиме.

---

### 2. Ошибка "database is locked" в SQLite

Эта ошибка возникает при одновременных операциях записи из разных транзакций.
- Убедитесь, что соединения всегда закрываются в блоке `finally` или через контекстные менеджеры `with get_db_connection() as conn:`.
- При вызове функций чтения из базы используйте режим только для чтения.

---

### 3. Модуль не появился в списке после создания папки в `modules/`

1. Проверьте наличие корректного файла `manifest.yaml` в директории модуля.
2. Проверьте валидность YAML синтаксиса в манифесте.
3. Перейдите в раздел **Модули** веб-интерфейса и нажмите кнопку **Пересканировать модули** (`POST /api/modules/scan`).
4. Ознакомьтесь с логами в `backend.log` на предмет ошибок импорта Python-файлов.

---

### 4. Ошибка CORS при обращении к API с другого IP/домена

Backend NMS WebUI включает поддержу CORS для всех источникоов. Если возникает ошибка:
- Проверьте наличие заголовков в Nginx (если используется проксирование).
- Убедитесь, что во фронтенде в `src/core/api.ts` используется корректный относительный путь `/api/` или переменная `VITE_API_URL`.
