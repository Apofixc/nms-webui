# Быстрый старт NMS WebUI

Подробное руководство по установке, разворачиванию и запуску платформы NMS WebUI для разработчиков и системных администраторов.

---

## 📋 Системные требования

### Минимальные требования к системе
- **Операционная система**: Linux (Ubuntu 20.04 LTS+, Debian 11+), macOS 12+, или Windows через WSL2.
- **Python**: Версия 3.10 или новее.
- **Node.js**: Версия 18.x или 20.x LTS + `npm` 9+.
- **Оперативная память**: Минимум 1 ГБ (рекомендуется 2 ГБ+).
- **Дисковое пространство**: 500 МБ для зависимостей и базы данных.

---

## 🚀 Пошаговая установка

### 1. Переход в директорию проекта
```bash
cd /opt/nms-webui
```

### 2. Запуск в режиме разработки (Dev Mode)
В проекте предустановлен управляющий скрипт `run_webui.sh`, который автоматически выполняет следующие шаги:
- Создаёт виртуальное окружение `.venv` (если не было создано).
- Устанавливает и обновляет зависимости Python (`pip install -r requirements.txt`).
- Проверяет и устанавливает npm-пакеты в `frontend/`.
- Запускает Backend (FastAPI / Uvicorn) на порту `8000`.
- Запускает Frontend (Vite Dev Server) на порту `5173`.

**Команда для запуска:**
```bash
./run_webui.sh dev
```

После успешно запуска в консоли появятся ссылки для доступа:
- 🌐 **Frontend (Веб-интерфейс)**: `http://localhost:5173`
- 🛠️ **Backend REST API**: `http://localhost:8000`
- 📚 **Interactive Swagger API Docs**: `http://localhost:8000/docs`

---

## ⚙️ Переменные окружения (.env)

Вы можете настроить параметры работы сервиса, создав или отредактировав файл `.env` в корне проекта `/opt/nms-webui/.env`:

```env
# Порт FastAPI backend
BACKEND_PORT=8000

# Порт Vite frontend dev server
FRONTEND_PORT=5173

# Отключение авторизации (только для отладки!)
NO_AUTH=false

# Путь к файлу базы данных SQLite
DB_PATH=/opt/nms-webui/nms.db
```

---

## 🔍 Решение проблем при запуске

### Конфликт портов (Port inside use)
Если порт `8000` или `5173` занят другим сервисом:
1. Измените порт в `.env` (например, `BACKEND_PORT=8080`).
2. Перезапустите `./run_webui.sh dev`.

### Сброс базы данных или повторная инициализация
База данных `nms.db` создаётся автоматически при первом старте backend. Если требуется сбросить состояние до дефолтного:
```bash
rm -f /opt/nms-webui/nms.db
./run_webui.sh dev
```
