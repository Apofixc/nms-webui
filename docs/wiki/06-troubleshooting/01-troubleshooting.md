# ❓ FAQ и Поиск решений (Troubleshooting)

---

## 🛠 Частые ошибки и пути их решения

### 1. Ошибка доступа к базе данных `nms.db: database is locked`
- **Причина**: Несколько процессов пытаются одновременно записать данные вне режима WAL.
- **Решение**: Проверьте, включен ли режим WAL для SQLite. В терминале выполните:
  ```bash
  sqlite3 nms.db "PRAGMA journal_mode=WAL;"
  ```

### 2. Сбой при запуске `./run_webui.sh` (Отсутствуют зависимости)
- **Причина**: Неполная или прерванная установка `pip` / `npm`.
- **Решение**: Пересоздайте виртуальное окружение и переустановите пакеты:
  ```bash
  rm -rf .venv frontend/node_modules
  ./run_webui.sh
  ```

### 3. Видеопоток MediaMTX не отображается в плеере (WebRTC/RTSP)
- **Причина**: Неверный RTSP URL камеры в `instances.yaml` или блокировка портов брандмауэром.
- **Решение**:
  1. Проверьте доступность порта MediaMTX (по умолчанию `8554` для RTSP, `8889` для WebRTC).
  2. Проверьте актуальные логи медиасервера в `mediamtx.yml`.

### 4. WebSocket соединение сбрасывается (`Connection Refused`)
- **Причина**: Несовпадение хоста или порта бэкенда в настройках фронтенда.
- **Решение**: Убедитесь, что параметры `HOST` и `PORT` в `.env` соответствуют адресу, запрашиваемому фронтендом.
